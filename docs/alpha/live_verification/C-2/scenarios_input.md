# C-2 라이브 재검증 시나리오 입력 텍스트

본 파일은 사용자가 알파 배포 환경에 입력할 시나리오 본문 7건을 정리한 것.
복사하여 알파 환경 입력 필드에 그대로 붙여넣기 후 라우팅 결과 캡처.

**출처**: `docs/alpha/alpha_scenarios.json` (G2-5 검증 시 사용된 원본, 1bit 변경 없음)
**시나리오 형식**: JSON 구조화 객체 → 표 형태로 정리 (발주문 §W-3 "객체 필드를 표 형태로 정리" 분기 적용)
**의역·요약 금지** — 모든 본문은 alpha_scenarios.json 원본 그대로 인용.

알파 환경의 자연어 입력 필드(예: `app/(care)/chat/page.tsx`)에는 표의 `primary_symptom` + `secondary_symptoms` + `duration` + `context` 를 자연스러운 문장으로 합쳐 붙여넣기 권고. 메타 필드(나이·성별·시각)는 입력 가능 시 함께 기입.

---

## ALPHA-008 (TIA 회복)

**기대 라우팅**: L1
**기대 정책**: AGENDA-12 (TIA 회복 후에도 L1 유지)
**기대 메시지 키워드**: `119` / `TIA` / `뇌졸중 전조` / `증상 사라져도`
**Validation focus**: TIA Type II 위험 (증상 호전이 안심 신호로 오판될 위험)

**입력 본문** (객체 원본):

| 필드 | 값 |
|---|---|
| primary_symptom | 일시적 어지럼증 |
| secondary_symptoms | 발음 어눌(현재 회복), 왼팔 무력감 30분 전 |
| duration | 30분 전 발생, 현재 호전 |
| context | 환자는 '괜찮다'고 함 |

**입력 메타 필드**:
- 나이: 75
- 성별: male
- 연령군: elderly
- 시각: 10:30 (daytime)

## AGENDA-18 (컨텍스트 감산 — 비응급) — 대표 원천 시나리오: ALPHA-025

**기대 라우팅**: L4 (컨텍스트 감산으로 비응급 레벨)
**기대 정책**: AGENDA-18 (기존 진단력 + 동일 증상 패턴 → 라우팅 다운그레이드)
**기대 라우팅 경로**: `regular_visit_or_self_care`
**기대 카드**: `SpecialtyRecommendationCard`
**기대 진료과**: 정신건강의학과
**기대 메시지 키워드**: `정신건강의학과` / `정규 진료` / `응급 신호 시 119`
**Validation focus**: 공황발작 — 흉통 키워드로 L1 과잉 라우팅 위험 검증

**입력 본문**:

| 필드 | 값 |
|---|---|
| primary_symptom | 흉통 |
| secondary_symptoms | 과호흡, 손저림, 공황 양상 |
| duration | 20분, 점차 호전 |
| context | 공황장애 진단력 5년, 동일 양상 반복 |

**입력 메타 필드**:
- 나이: 30
- 성별: female
- 연령군: adult
- 시각: 22:00 (evening)

**AGENDA-18 변종 시나리오** (필요 시 추가 검증):
- **ALPHA-026** (편두통): 두통 + 편측 + 광 과민 + "편두통 진단력, 평소 패턴과 동일" → L5
- **ALPHA-027** (만성 위염): 복통 + 식후 발생 + "만성 위염 진단력, 동일 양상 반복" → L5

본 §3.2.7 캡처는 ALPHA-025 1건이 기본. 1건이라도 L1·L2 등 응급 레벨로 오라우팅되면 P0 미통과.

## 참고: 모든 7건 공통 입력 모드

본 검증의 자연어 입력은 `app/(care)/chat/page.tsx` 의 자유 텍스트 입력 필드를 사용. 표의 필드 값을 다음 순서로 자연스럽게 합쳐 입력 권고:

```
[primary_symptom]이/가 [duration]. [secondary_symptoms를 콤마로 나열]. [context].
```

**예시 (ALPHA-008)**:
> 일시적 어지럼증이 30분 전 발생, 현재 호전. 발음 어눌(현재 회복), 왼팔 무력감 30분 전. 환자는 '괜찮다'고 함.

메타 필드(나이·성별·연령군·시각)는 입력 가능 필드가 있으면 함께 기입.

**시나리오 본문 원본 검증**: 본 파일의 모든 필드 값은 `docs/alpha/alpha_scenarios.json` 원본과 1bit 일치. 시나리오 모듈 무수정.
