### §3.1 Access mode 변경 사유 (private → public)

`@vercel/blob@2.3.3` 의 `put()` API 는 `access: 'public'` 만 지원 (private 옵션 deprecated). v13 §10 PII 정책 정합을 위한 대체 방어:

1. **`addRandomSuffix: false`** — Blob URL 이 `consent/<alpha_code>.json` 패턴으로 고정되어, alpha_code 를 모르는 외부자는 URL 추측 불가
2. **`alpha_code` 자체가 비밀 자원** — `ALPHA_USER_CODES` 환경 변수에만 존재, git 미추적 (`.env.local` `.gitignore:34` 보호)
3. **저장 PII 없음** — alpha_code (의미 없는 임의 코드) + ISO timestamp + session_hash (익명) + boolean 4건. 개인 식별자 0건
4. **노출 시 영향 한정** — 동의 사실 확인뿐 (체크박스 4건). 진료 정보·연락처 등 민감 데이터 무관

추가 강화 권고 (LAUNCH-0 시점):
- Vercel Blob Store 자체에 access control 설정 (Vercel Dashboard Storage → Blob → Access Control)
- 또는 D안 마이그레이션 (Supabase RLS 또는 자체 DB) 별도 사이클 검토
