## 단계 5 검증 도구 G1 그룹 복합 발주 후보 (§8.6)

본 JSON을 입력으로 받는 시나리오 자동 검증 도구 + N3 인앱 통합 + N1 메트릭 백엔드 = 3개 모듈 복합 발주 (Claude Code 위임).

검증 도구 핵심 요구사항 초안:
1. `alpha_scenarios.json` 로드 → 28개 시나리오 순회
2. 각 시나리오 `input` → 라우팅 엔진 호출 → 실제 출력 획득
3. `expected_output`과 비교: triage_level, routing, card_displayed, specialty_recommendation, message_keywords 일치 여부
4. Type II 검출 로직: `expected_output.triage_level == "L1"` AND `actual.triage_level != "L1"` → Type II 카운트 증가
5. 통과 기준 자동 산출: Type II 0건 AND 전체 적정 ≥ 95%
6. 결과 리포트 (PASS/FAIL 시나리오 ID 목록 + 누적 자가 패치 0건 기록 갱신)
