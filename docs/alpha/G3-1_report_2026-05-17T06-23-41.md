ALPHA-0 §3 게이트 P0 4건 + P1 3건 = 자동 검증 항목 7/7 통과. 잔여 항목은 사용자 외부 (B안 트랙 2) 또는 LAUNCH-0 이연. v13 §5.1 단계 2 (알파 5명 후보 확정 + 동의 절차 실행) 즉시 진입 가능 상태.
