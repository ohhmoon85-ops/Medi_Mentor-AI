### 핵심 규약

**`decision-engine.ts`**:
```typescript
export function analyzeChecklist(input: ChecklistInput): ChecklistResult {
  // 1단: 위급 신호 검사
  const urgent = checkUrgentTriggers(input.checkedSymptoms);
  if (urgent) return buildUrgentResult(urgent, input);
  
  // 2단: 부위 조합 매칭
  const matches = matchCombinations(input.region, input.checkedSymptoms);
  if (matches.length > 0) return buildMatchResult(matches, input);
  
  // 3단: 일반 안내
  return buildGeneralResult(input);
}
```

**`prompt.ts`** — LLM 자연어 변환 (선택적):
```
당신은 닥터홈 체크리스트 결과 자연어 변환 도구입니다.
- 입력: decision-engine이 결정한 KTAS, 진료과, 잠정 가능성 2~3건 (★ 고정 입력 — 변경 금지)
- 출력: 사용자에게 친근하게 안내 (의사 자식 톤)
- 단언 어휘 절대 금지: "진단합니다", "확진", "확실히", "○○병입니다"
- 허용 어휘: "추정", "가능성", "이런 양상이 관찰됩니다", "참고 가능"
- 응답 끝에 반드시 "본 안내는 추정이며 자세한 진단은 병원 방문이 필요합니다" 포함
- 자살 충동 분기 시: 1393 자살예방 상담전화 안내 최우선
```

LLM 응답 사후 검증: D1 `lib/vision/safety-rules.ts`의 FORBIDDEN_PATTERNS 재사용 (cross-module dependency 추가).

## ▶ D2-4 — API 라우트 신설 + Vision 결합

### 신규 파일

`app/api/checklist/route.ts` (~150라인)

### 입력 스펙

```typescript
POST /api/checklist
Body: {
  region: RegionId;
  checkedSymptoms: string[];
  duration: 'just_now' | 'within_hour' | 'today' | 'days' | 'week_plus';
  intensity: 'mild' | 'moderate' | 'severe' | 'extreme';
  freeText?: string;
  images?: string[];  // base64 (피부·외상만, 최대 3장)
  guardianTarget: 'self' | 'family' | 'child' | 'elder';
}
```

### 출력 스펙

```typescript
{
  matches: Array<{ name: string; characteristics: string; confidence: 'high'|'medium'|'low' }>;
  ktas: 'L1'|'L2'|'L3'|'L4'|'L5'|'special';
  specialty: SpecialtyCode;
  supplements?: Supplement[];  // lib/supplements/ 매핑
  visionResult?: VisionAnalysis;  // 사진 첨부 시 /api/vision 호출 결과
  immediateAction?: { type: string; hotline?: string; message: string };
  disclaimer: string[];  // 7건
  naturalLanguageResponse?: string;  // LLM 변환 (선택, 옵션)
}
```

### 처리 흐름

1. decision-engine.analyzeChecklist() 호출 → 1차 결과
2. 사진 첨부 + region이 SKIN 또는 LIMBS면 → `/api/vision` 호출, 결과 결합
3. 자살 충동 분기 시 → immediateAction에 1393 즉시 표시
4. matches가 있으면 → supplements 매핑 추가
5. LLM 자연어 변환 (선택, env flag로 on/off)
6. 면책 7건 항상 포함

### 안전 처리

- 사진 base64 전송 후 즉시 메모리 해제 (D1과 동일)
- 로그에 입력 데이터 일체 출력 금지
- 응답 후 입력 객체 dereference

### D2-4 자율 검증 ≥ 8건
